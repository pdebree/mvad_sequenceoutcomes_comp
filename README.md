# Sequence Outcomes Files

Files 
- seqout_utils.R - Contains functions used in Linear, Non-Linear and Simulated Data Competitions. 
- mvad_linear_comp_cv.R - Contains full linear competition (not including sequence metrics) to be run on HPC with 20 cvs
- mvad_nonlinear_comp_cv.R - Contains full nonlinear competition (not including sequence metrics) to be run on HPC with 20 cvs
 

Directories:
- cv_outputs - Contain results from various MVAD runs (linear and nonlinear)
- hpc_jobs_code - Contains sbatch files with configurations of hpc jobs 
- plots - Contains plots created for analysis
- plots_code - Contains files used in creating plots
- sensitivity_analysis - Contains files for running various iterations of the linear and non-linear competitions, with altered parameters
- sequence_metric_eval - Contains files for evaluating Sequence Metrics as covariates for both linear and non-linear competitions.
- sims_outputs - Contains files for sim study results
- sims_eval_files - Contains files for running simulated data evalution
